# Created2Build Website

This is a Vercel-ready React + Vite website for Created2Build.

## Local preview

```bash
npm install
npm run dev
```

## Vercel deploy settings

- Framework Preset: Vite
- Build Command: `npm run build`
- Output Directory: `dist`
